## Your agents just left the desk 🎮

Agent Controller turns a DualSense into a live remote for the Claude Code and Codex sessions you
already have running.

### Highlights

- Hear agent replies and open questions through the controller speaker.
- Hold the mic button to dictate an answer into the selected live session.
- Switch between Claude, Codex, and every discovered session with the shoulder buttons.
- Feel questions through haptics and see the selected agent on the controller light.
- Choose any speech and dictation language installed on macOS.

### Download

Download **`Agent Controller-1.0.0-arm64.dmg`** below, open it, and drag Agent Controller into
Applications. The app is signed, notarized, and stapled for Gatekeeper.

This first release supports **Apple silicon Macs running macOS 14 or newer**. Connect the
DualSense over USB for speaker and microphone audio; buttons, light, and haptics also work over
Bluetooth.

Checksums for both downloadable builds are in `SHA256SUMS.txt`.
